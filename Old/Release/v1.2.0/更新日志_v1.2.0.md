# Modbus CRC 工具 v1.2.0 更新日志

发布日期：2026-03-26

## 版本说明

`v1.2.0` 继续面向远程维护调试场景，重点整理并恢复了 Modbus RTU 原始帧生成工具，方便快速生成、校正并复制现场维护报文。

## 本次更新

- 重新整理并发布 Windows 版 Modbus RTU 原始帧生成器。
- 支持根据从站地址、功能码、寄存器地址和数据值自动生成原始帧。
- 支持自动计算 Modbus CRC16，并在生成后自动复制结果到剪贴板。
- 支持 HEX / DEC 两种输入方式切换，减少手工换算。
- 支持直接导入已有原始帧，并自动校正 CRC 后重新复制。
- 新增回收站窗口，可回看最近导入过的原始帧内容。
- 增加下一步操作提示，方便直接粘贴到网络调试工具中发送。

## 适用范围

- 当前工具主要面向 `06` 单寄存器写入类原始帧生成与校验。
- 原始帧导入当前支持 6 字节或 8 字节格式的单寄存器报文。
